# App_Cryp_Assignment_1_OTP
Create a one time pad encryption, and a substitute cipher.
Requirements
1. Substitution Cipher

Encrypt the message “this is an exercise” using one of the following ciphers.

Ignore the spaces between words. Decrypt the message to get the original plaintext.

a. Additive cipher with key = 20

b. Multiplicative cipher with key = 15

2. One-Time Pad Encryption

The one-time pad encryption of plaintext mickey (when converted from ASCII to binary in the standard way) under key k is:

                  10000100 00000111 01010100 00011100 00011101 01111001.

a. What is the one-time pad encryption of the plaintext donald under the same key?

Use this link http://sticksandstones.kstrom.com/appen.html to convert each letter's ASCII to binary.

b. Redo the Python programming for encryption/decryption of OTP encryption
